# CAD

This directory contains the mechanical design files for the REFLEX enclosure.

## Design Tool
Autodesk Fusion 360

## Planned Files
- `source/` - editable Fusion 360 source files
- `stl/` - exported 3D-printable parts

## Design Requirements
The enclosure was designed around the Arduino Mega 2560, custom perfboard, 16x2 LCD, four 30 mm illuminated arcade buttons, internal slim USB power bank, short USB-A to USB-B power cable, and removable service access.

The internal layout prioritizes serviceability and avoids stacking the Mega, perfboard, and battery directly on top of each other.
