# Hardware

This directory documents the electrical design and permanent perfboard implementation for REFLEX.

## Subdirectories
- `schematic/` - circuit diagrams and electrical schematics
- `perfboard/` - perfboard layout and build documentation
- `wiring/` - wiring diagrams and harness documentation

## Major Hardware
- Arduino Mega 2560
- 3 x 2N2222A NPN transistor LED drivers
- 3 x 1 kOhm transistor base resistors
- 5 x 220 Ohm LED/backlight current-limiting resistors
- 4 x illuminated arcade buttons
- 16x2 HD44780-style LCD
- 10 kOhm LCD contrast potentiometer
- passive buzzer
- custom perfboard
- internal USB power bank
