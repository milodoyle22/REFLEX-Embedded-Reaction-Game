# Firmware

This directory contains the Arduino firmware for REFLEX.

## Target
- Arduino Mega 2560
- Arduino IDE
- C++

## Main Firmware
The final game firmware will live here as `REFLEX.ino`.

The firmware implements the game as a finite-state machine and handles button inputs, random cue timing, reaction-time measurement, false starts, wrong-button responses, scoring, LCD output, buzzer feedback, and illuminated button control.
